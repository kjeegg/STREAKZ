# 🔥 Streakz – Habit Tracker App

Welcome to **Streakz**, the beautifully simple and engaging app designed to help you build and maintain healthy habits effortlessly. Track your progress, set reminders, complete daily challenges, and celebrate your achievements!

## 📱 Screenshots

### 🏠 Home Screen
Here you'll find all your daily habits neatly organized. See at a glance what's scheduled for today.

![Home Screen](screenshot_home.png)

### ➕ Adding a New Habit
Create a new habit by specifying the title, selecting days of the week, setting the reminder time, and personalizing the color.

![Add Habit Screen](screenshot_add_habit.png)

### ✅ Habit Added
Once added, your habit is easily accessible on the home screen. Mark it complete to maintain your streak!

![Habit Added](screenshot_habit_added.png)

### 📈 Track Your Streak
Monitor your streaks and earn XP to level up. Stay motivated by seeing your longest streak clearly displayed.

![Streak and Progress](screenshot_progress.png)

### 🏆 Challenges
Participate in exciting daily and weekly challenges that encourage you to keep your habits going strong.

![Challenges](screenshot_challenges.png)

### 🎖️ Achievements
Unlock and collect achievements by maintaining your habits consistently. Celebrate your milestones and stay inspired!

![Achievements](screenshot_achievements.png)

## 🚀 Features
- **Habit Scheduling**: Choose specific days and times for each habit.
- **Streak Tracking**: Maintain your streak and build powerful routines.
- **XP and Leveling System**: Earn experience points as you build habits.
- **Interactive Challenges**: Stay engaged with fun habit challenges.
- **Achievement System**: Celebrate your habit milestones.
- **Customizable Reminders**: Never miss a habit again.

## 🛠️ Technologies
- **Flutter**: Cross-platform UI toolkit for crafting beautiful apps.
- **Dart**: Programming language optimized for building user interfaces.
- **Firebase**: Backend services for authentication, data storage, and analytics.

## 💡 Why Streakz?
Streakz is designed with simplicity and motivation in mind. It transforms habit-building into an enjoyable experience, making it easier for you to stay consistent and achieve your personal goals.

## 🛠️ Installation
1. Clone the repository:
```bash
git clone https://github.com/kjeegg/STREAKZ/tree/ver-firebase
```
2. Navigate to the project directory:
```bash
cd streakz
```
3. Install dependencies:
```bash
flutter pub get
```
4. Run the app:
```bash
flutter run
```
