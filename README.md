# 🔥 Streakz – Habit Tracker App

Welcome to **Streakz**, the beautifully simple and engaging app designed to help you build and maintain healthy habits effortlessly. Track your progress, set reminders, complete daily challenges, and celebrate your achievements!

## 🚀 Features
- **Habit Scheduling**: Choose specific days and times for each habit.
- **Streak Tracking**: Maintain your streak and build powerful routines.
- **XP and Leveling System**: Earn experience points as you build habits.
- **Interactive Challenges**: Stay engaged with fun habit challenges.
- **Achievement System**: Celebrate your habit milestones.
- **Customizable Reminders**: Never miss a habit again.

## 🛠️ Technologies
- **Flutter**: Cross-platform UI toolkit for crafting beautiful apps.
- **Dart**: Programming language optimized for building user interfaces.
- **Firebase**: Backend services for authentication, data storage, and analytics.

## 💡 Why Streakz?
Streakz is designed with simplicity and motivation in mind. It transforms habit-building into an enjoyable experience, making it easier for you to stay consistent and achieve your personal goals.

## 🛠️ Installation
1. Clone the repository:
```bash
git clone https://github.com/kjeegg/STREAKZ/tree/ver-firebase
```
2. Navigate to the project directory:
```bash
cd streakz
```
3. Install dependencies:
```bash
flutter pub get
```
4. Run the app:
```bash
flutter run
```
